**解读**：

- **传输层由 `uni.*` 承担，SDK 只做协议编解码（打包 / 解包 / 校验）**。
- uni-app 编译到 **mp-weixin** 时 `uni.*` **映射为 `wx.*`** → **该 SDK 原则上可在微信小程序端运行**。
- ⚠️ **文档中「小程序」/「mp-weixin」命中 0 次** → **厂商未声明支持小程序端**，编译可行性**须实测**，我方不得替厂商宣称。
