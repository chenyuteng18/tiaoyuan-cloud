## 一、应用图标规范

### 1.1 总体原则（P0 红线）
- **严禁 emoji 作功能图标**：所有图标必须是统一描边、可矢量缩放、语义明确的 **SVG 图标方案**。图标库由后续设计输出环节在 Spec 中锁定**一套**，三端共用、不混用、不自创第二套。（本专家团 P0 绝对规则第 1 条）
- **禁止紫粉渐变主视觉**：本产品主色为深绿 `brand #2D5A4A` + 暖米 `bg #FAF8F4`，天然避开紫粉套路；任何渐变只允许"同色系深浅渐变"（如 `brand #2D5A4A → brandDark #22463A`）。
- **颜色一律走令牌**：文档/代码中出现颜色必须引用令牌名（如 `brand`/`bg`），唯一例外是引用令牌本身的规范值时写 `#2D5A4A` 并标注 `= brand`。
- **禁止 AI 模板味文案**：图标命名、占位文案不得出现"空洞英文占位 / 通用欢迎套话"等 AI 模板套路。

### 1.2 品牌令牌引用（与代码同源，不得另立色板）
| 角色 | 令牌 | 值 | 用途 |
|---|---|---|---|
| 品牌主色 | `brand` | `#2D5A4A` | 图标描边/主体 |
| 品牌深 | `brandDark` | `#22463A` | 同色系深渐变端 |
| 品牌浅 | `brandLight` | `#3C7360` | 同色系浅渐变端 |
| 承载底色 | `bg` | `#FAF8F4` | 图标面/留白 |
| 表面 | `surface` | `#FFFFFF` | 浅底变体 |
| 表面备选 | `surfaceAlt` | `#F2EEE7` | 次级面 |
| 边框 | `border` | `#DED7CB` | 分隔/描边辅助 |
| 文本 | `text` / 端C `textAlt` | `#1F2933` / `#23302B` | 文字 |
| 文本次 | `textMuted` | `#5B6670` | 次要文字 |

> 端 A / 端 B 另有内部语义色（`ok #2F7A4F` / `warn #A96B14` / `danger #A3312A` / `info #2C5F8A`，端 A 还有 `frozen #6B5B95` / `pending #8A6D3B`）。**端 C 刻意无语义分级色**（契约 R8 禁用"不利"色与措辞）——图标体系对端 C 也不得引入红/黄/绿状态色。

### 1.3 三端共用一族：角色区分方案
三端**共用同一母题（mark）**，仅以细节/配色区分角色，避免"同一个系统三个绿 / 三个图标"。

| 端 | 角色定位 | 区分手法（不换母题） |
|---|---|---|
| 端 A · 管理端 | 权威 / 结构性 | `brand` 实心方块底 + `bg` 母题（最"重"，强调后台权威） |
| 端 B · 调理师·经络师端 | 专业 / 操作 | `brand` 描边方框 + `bg` 底 + 一个"经络端点"强调点（次之，强调专业动作） |
| 端 C · 客户端 | 日常 / 亲和 | `brand` 描边 + `bg` 底 + 圆角更柔（最"轻"，强调陪伴感） |

> 强调色用量纪律：每屏 ≤ 2 处 `brand` 可见使用。

### 1.4 尺寸、圆角、留白规格
**商店主图标（应用图标本体）**
| 用途 | 尺寸 | 格式 | 圆角 | 留白（安全边距） |
|---|---|---|---|---|
| Google Play / 通用商店 | **512 × 512** | 32-bit PNG（实底，无透明） | 按平台自适应蒙版；自绘圆角建议 `64px`（=12.5%，对齐 `RADIUS.lg` 比例） | 母题四周留白 **≥ 12.5%**（活动区控制在 ~384px 内） |
| 桌面/启动器 | 512 / 256 / 128 | PNG / SVG | 同上 | 同上 |
| 自适应密度 | 48 / 96 / 192 | PNG（按 mdpi~xxxhdpi）或单 SVG 矢量缩放 | — | — |

**安卓 Adaptive Icon（端 B 原生）分层**
- 背景层（background）：108×108 dp 全幅，导出建议 `432×432`（xxxhdpi）或按密度组 `48/72/96/144/192`。
- 前景层（foreground）：108×108 dp，关键图形落在 **72×72 dp 安全区**（居中、四周留 18dp）。
- 蒙版由平台决定（圆形/圆角方/squircle），故前景**不得依赖外圈形状**，图形必须自包含于安全区。

**微信小程序（端 C）**
- 小程序头像：**144 × 144** PNG（实际上传会被裁为圆形/方形，母题须居中且四周留白充足）。
- TabBar 图标：81 × 81 px（选中/未选中两态），纯 `brand` 描边线性图标，未选中用 `textMuted` 描边。

### 1.5 功能性图标（in-app，非商店）尺寸与体系
应用内导航/功能图标统一来自**锁定的同一 SVG 图标集**，三档尺寸：
- 行内图标：**16px**
- 按钮内图标：**20px**
- 独立图标：**24px**

> 一切功能性图标用 SVG `stroke`（描边）实现，线宽按 24px 基准 `1.5–2px`，等比缩放。
> **绝对禁止**用彩色图形符号（如火箭、火焰、灯泡等 emoji）充当功能图标——这是本专家团 P0 第 1 条，违反即退回。
